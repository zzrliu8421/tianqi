# 测 · 官方值对照记录(AQI 校准证据链)

方法论:自算 AQI 用 HJ 633-2012 分段线性插值(与前端 calcCNAQI 同一套断点,CO 按 µg/m³→mg/m³ 换算);彩云 aqi.chn 与和风 v7/air/now 为各自上报的国标 AQI;中国天气网为人工同屏抽查位。注意方法学差异:自算输入是**实时浓度**(与页面展示同口径,非官方逐日 24h 均值),与上报值的差值本身即记录对象——持续同向偏离说明自算实现或输入口径有系统性问题,偶发小差值属预期。彩云 vs 和风的差值反映供应商间实测离散度,是「多源交叉验证」必要性的又一实证。

生成:node tracker/official-aqi.js(CI 每日自动,重跑覆盖当日)。
